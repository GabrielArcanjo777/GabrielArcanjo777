## Projetos

### Produto e segurança

#### [CyberAlerta Guardian](https://github.com/GabrielArcanjo777/cyberalerta-guardian)

MVP de proteção assistida contra golpes e engenharia social em mensagens. Reúne backend FastAPI, frontend Next.js, aplicações Android e Windows, análise de risco explicável, autenticação, auditoria e testes automatizados.

Python · FastAPI · Next.js · TypeScript · Kotlin · Tauri

### Backend e automação

#### [B2BFlow](https://github.com/GabrielArcanjo777/b2bflow-python-supabase-zapi-mvp)

Worker em Python que consulta contatos autorizados no Supabase e integra o envio de mensagens pela Z-API. O projeto prioriza configuração por ambiente, modo de simulação, proteção de credenciais e prevenção de envios acidentais.

Python · Supabase · REST API · Z-API · unittest

### Cloud e documentação

#### [Resumos Microsoft Azure](https://github.com/GabrielArcanjo777/dio-azure-resumos)

Base de conhecimento sobre serviços, máquinas virtuais, bancos de dados e arquiteturas no Azure. Os documentos seguem uma estrutura validada automaticamente pelo GitHub Actions.

Azure · Cloud · Python · GitHub Actions · Documentação
